# 从内容锁定到最终版：可迁移的决策链

这个 example 只保留最终成立且可迁移的决策闭环，不展开与复现无关的中间版本。

这里只保留最终成立的闭环：

```text
核心 cut 产物
  → 音画锁定
  → 包装方向探索
  → 看片并给出具体反馈
  → 只解冻对应层做 conform / 再剪
  → 验证修改项与冻结项
```

## 1. 核心 cut 与音画锁定

最终采用的内容基线完成了四件事：

- 多集素材只围绕“死去的白月光成为准大嫂，男主逐步确认她仍在意自己”这一条关系线。
- “大嫂”“日日夜夜……挫骨扬灰”“有我在，你别怕”三段原声保持 1.0×，旁白在画面建立后进入。
- scene-change / 亮度检测辅助定位了护人段附近的强曝光叠化，真实播放后把入点收进稳定画面。
- 亲吻与护人反应保留到情绪落地；交代性镜头更短，关键表演更长。

对应公开产物：`clip_plan.json`、`narration.json`、`timeline.json`、`assembly_qc.json`。复现时由 Skill 重新生成 `clip_plan_validated.json`。

锁定后，旁白、三段原声、混音和基本画面不应在包装探索中漂移。

## 2. 在锁定母版上收敛包装

包装阶段加入字幕信息条、片名标识和低频花字。看片反馈没有要求重剪故事，而是逐层收敛：

- 片名删除“短剧 / 60 秒看懂”等说明性标签，只保留作品名。
- 片名横排进入上方黑边，不侵入主体画面。
- 花字改为补充潜台词，不复述字幕，并按镜头负空间落位。
- 字幕重新绑定实际 placed audio；TTS 保持完整思路，字幕独立拆为阅读 cue。
- 纯白底改为暖灰白，字体、描边、阴影和图标层级继续减法。

对应公开产物：`captions.json` 与 `remotion/`。Remotion 是音画锁定后的项目级透明包装，不是核心 Skill 依赖。

## 3. 看片后只解冻画面 conform

最终完整看片确认了两处需要优化连续性的接点：

- 约 42.08 秒存在人为尾帧停留，造成动作停顿感。
- 约 46.24 秒把同一个运动长镜头中间一段删掉，造成跳接。

本轮只解冻画面：恢复源连续运动，不加溶解、闪白或其他遮掩；旁白、原声、音效、字幕、片名和花字全部冻结。`picture-conform.json` 直接描述最终接受的画面映射。

对应公开产物：`edit-map.json`、`picture-conform.json`、`delivery-qc.json`。

## 4. 可迁移的 REVISION 记录方式

每轮看片意见都应写成三项，而不是重新跑一次 CREATE：

1. **change set**：这轮必须改变什么，以及观看证据。
2. **frozen set**：哪些故事、镜头、声音、字幕或包装已经通过，不得漂移。
3. **verification**：修改项是否真的改变，冻结项是否保持，最终文件是否完整看过。

本案例的机器可读记录见 `revision-log.json`。公开复现只使用最终采用的判断，由 `video-recap` Skill 编排，见 `skill-runbook.md`；不存在绕开 Skill 的一键重建脚本。
